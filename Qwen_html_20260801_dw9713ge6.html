📱Команды бота

/start — список команд
/balance — баланс копилок
/income 50000 ЗП — добавить доход
/spend 1500 Еда — трата из «Трат»
/spend 1500 Еда|inv — трата из «Инвестиций»
/invest 10000 Проект|spend — вложение
/when 50000 — когда смогу потратить
/when 50000|inv — из конкретной копилки
/list — последние 10 операций
/help — помощь

ℹ️Как это работает

📈 Инвестиции (33%) — треть каждого дохода автоматически идёт сюда.

🛋️ На диван (10%) — подушка безопасности и крупные цели.

💸 Траты (57%) — повседневные расходы.

📊 Вложения — когда берёшь из копилки, чтобы вложить в проект. Указывается откуда взял.

🔮 Прогноз — введи сумму и узнай точную дату, когда сможешь её потратить. Система учтёт все запланированные доходы и траты на годы вперёд.

🔍 Поиск — ищет по описанию, сумме, дате, категории, копилке.

🤖 Telegram-бот — встроен прямо в сайт. Пока вкладка открыта — бот работает. Пишешь боту → меняется на сайте. Меняешь на сайте → бот видит.

📥 Бэкап — скачай JSON → загрузи на другом устройстве.

⚠️ Данные хранятся в браузере (localStorage). Регулярно делай бэкапы!
